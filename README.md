## 📋 الفكرة وطريقة العمل

* المتجر مصمم لجمهور السوق المصري، بواجهة عربية كاملة RTL وتصميم فخم وأنيق بألوان كريمية (#FAF5EA) وبني ملكي (#4A2C1A) وذهبي (#C9A24B).
* لا يتطلب المشروع أي قواعد بيانات معقدة أو تكاليف استضافة شهرية.
* إتمام الطلب يتم مباشرة عبر **محادثة واتساب مجهزة برسالة تفصيلية** تضم اسم العميل، هاتفه، محافظته، وعناوينه، وتفاصيل المقاسات والأسعار، والدفع نقداً عند الاستلام.
* يدعم نمطين للبيع: **القطاعي للعملاء** و **عروض وشرائح الجملة للتجار**.

## 🚀 دليل الخطوات من الصفر حتى استلام تطبيق الأندرويد (APK)

### الخطوة 1: تجهيز وتسمية صور السجاد (~700 منتج)
السكريبت المدمج ذكي جداً، ويقرأ بيانات وصور السجاد تلقائياً بناءً على اسم الصورة:

1. **اسم الصورة الرئيسية للسجادة:**  
   ضع اسم الفئة بالإنجليزية ثم شرطة ثم رقم الموديل، مثل:
   * `modern-001.jpg` (لسجاد المودرن)
   * `classic-002.jpg` (لسجاد الكلاسيك)
   * `kids-003.jpg` (لسجاد الأطفال)
   * `kitchen-004.jpg` (لسجاد المطبخ والممرات)
   * `prayer-005.jpg` (لسجاد الصلاة والمساجد)
   * `moquette-006.jpg` (للموكيت والرولات)
   * **ملاحظة:** أي صورة تضع لها رقماً فقط مثل `001.jpg` أو `050.jpg` ستعتبر تلقائياً سجاد "مودرن".

2. **صور إضافية لنفس الموديل (معرض الصور):**  
   إذا كان للموديل أكثر من زاوية تصوير، سَمِّ الصور الإضافية هكذا:
   * `modern-001-2.jpg`
   * `modern-001-3.jpg`

3. ضع كل الصور داخل المجلد:  
   `www/images/products/`

### الخطوة 2: ضغط الصور لتسريع التصفح وتصغير حجم التطبيق
700 صورة بجودة الكاميرا الأصلية قد يتجاوز حجمها 3 إلى 5 جيجابايت! المطلوب هو ألا تتجاوز كل صورة 200 كيلوبايت.

**طرق الضغط المتاحة:**
* **الطريقة التلقائية (باستخدام Node.js):**  
  افتح التيرمينال واكتب:
  ```bash
  npm install
  npm run compress
  ```
  سيقوم السكريبت بتحجيم الصور لعرض 1000px وضغطها لتصبح خفيفة جداً.
* **بدائل مجانية وسهلة بدون أكواد:**
  1. موقع [Squoosh.app](https://squoosh.app) من جوجل (ضغط عالي الجودة).
  2. موقع [iLoveIMG](https://www.iloveimg.com/compress-image) لضغط مئات الصور دفعة واحدة مجاناً.
  3. تطبيقات الموبايل المجانية مثل: "Photo Compress & Resize" على متجر Play.

### الخطوة 3: توليد كتالوج السجاد تلقائياً
بعد وضع الصور المضغوطة في `www/images/products/`، نفّذ الأمر التالي:
```bash
npm run generate
```
أو ببساطة: **لا تقلق!** إذا قمت برفع الصور مباشرة إلى GitHub، فإن سيرفرات GitHub ستقوم بتشغيل هذا الأمر تلقائياً عند بناء التطبيق والموقع.

### الخطوة 4: ضبط رقم الواتساب والأسعار في `config.js`
افتح الملف: `www/js/config.js` في أي محرر نصوص (مثل المفكرة Notepad أو VS Code):
* **تغيير رقم الواتساب:**  
  عدّل السطر:
  ```javascript
  const WHATSAPP_LOCAL = "01280988369";
  ```
* **تعديل أسعار مقاسات السجاد الافتراضية:**  
  ستجد قائمة `SIZE_PRICES` مقسمة بالفئات (مودرن، كلاسيك، أطفال...). يمكنك تعديل السعر لأي مقاس، وسيتم تحديثه في كل السجاد فوراً!
* **تعديل رمز قفل الإدارة:**  
  عدّل `ADMIN_PIN = "2026";`.

### الخطوة 5: رفع المشروع إلى حسابك على GitHub
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم `md-carpets`).
2. ارفع ملفات المشروع إليه.
   > 💡 **نصيحة للمجموعات الكبيرة من الصور:**  
   > إذا كنت ترفع أكثر من 700 صورة (100-200 ميجابايت)، يُفضل استخدام برنامج **GitHub Desktop** السهل والمجاني، أو رفع الصور على دفعات (مثلاً 100 صورة في كل مرة).

---

### الخطوة 6: تحميل ملف تطبيق الأندرويد جاهزاً (APK)
بمجرد رفع المشروع إلى GitHub:
1. ادخل على صفحة المستودع في GitHub.
2. اضغط على تبويب **Actions** في الأعلى.
3. ستجد مهمة تعمل باسم `Build MD Carpets Android APK`.
4. انتظر 3 إلى 5 دقائق حتى تكتمل وتظهر علامة الصح الخضراء ✅.
5. اضغط على اسم المهمة، ثم انزل لأسفل الصفحة عند قسم **Artifacts**.
6. ستجد ملفاً باسم **`MD-Carpets-APK`**، اضغط عليه لتحميله فوراً على هاتفك أو كمبيوترك وتثبيته!

---

### الخطوة 7: تفعيل الموقع المجاني على GitHub Pages
1. ادخل على صفحة المستودع على GitHub ثم اضغط على **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت خيار **Build and deployment**، اختر:
   * Source: **GitHub Actions**.
4. انتظر دقيقة واحدة، وسيظهر لك رابط موقعك الرسمي المجاني لترسله لعملائك أو تضعه في إعلانات فيسبوك وتيك توك!

## 🖼️ التحكم في حجم التطبيق وسرعة التصفح (Bundled vs Remote)

في ملف `www/js/config.js` تجد خياراً مهماً:
```javascript
const IMAGES_MODE = "bundled"; // أو "remote"
```

1. **وضع `"bundled"` (الافتراضي):**  
   * الصور تكون مدمجة بالكامل داخل التطبيق والـ APK.
   * الميزة: التطبيق يعمل حتى لو كان هاتف العميل بدون إنترنت.
   * الملاحظة: حجم الـ APK قد يصل لـ 100-140 ميجابايت إذا كان هناك 700 صورة.

2. **وضع `"remote"` (موصى به لتصغير حجم الـ APK):**  
   * الصور تُرفع على رابط موقعك المجاني (GitHub Pages) ويقوم التطبيق بجلبها عبر الإنترنت.
   * الميزة: حجم الـ APK سيكون صغيراً جداً (أقل من 6 ميجابايت فقط!).
   * إذا انقطع الإنترنت، يظهر التطبيق إطاراً بديلاً أنيقاً باسم السجادة ورقم الموديل تلقائياً بدون أي أخطاء.

## 🛠️ لوحة التحكم البسيطة (#/admin) وكيفية نشر تعديلاتك

* يمكنك الدخول للوحة الإدارة بكتابة `#/admin` بعد رابط الموقع، أو عبر زر مخصص.
* الرمز الافتراضي: `2026`.
* **تنبيه:** هذا القفل هو قفل واجهة استخدام محلي لتنظيم العمل وليس نظام حماية سحابي معقداً.
* يمكنك من خلالها:
  * تغيير سعر أي موديل أو عمل خصم عليه (مثلاً خصم 15%).
  * وضع شارة "كمية محدودة" أو تعليم الموديل كـ "غير متاح حالياً".
  * استبدال صورة السجادة.
* **كيف تطبق هذه التعديلات لجميع الزبائن؟**
  1. اضغط على زر **"تصدير التعديلات"** ليتم تحميل ملف باسم `overrides.js`.
  2. ضع هذا الملف داخل مجلد `www/data/overrides.js` في المشروع وارفع التعديل على GitHub.
  3. سيتم فوراً تحديث الموقع والتطبيق لجميع العملاء!
